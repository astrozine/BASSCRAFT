# BASSCRAFT Asset Directory Guide

Place your actual product videos, photography, and font files in this folder structure:

## 1. Video Files (`assets/videos/`)
- `hero_desktop.mp4` — Horizontal (16:9) Hero / Light Tunnel video
- `hero_mobile.mp4` — Vertical (9:16) Hero video
- `hero_square.mp4` — Square (1:1) Hero video
- `no_bluetooth.mp4` — Wired USB-C / AUX cable plug-in video
- `controller_3d.mp4` — 3D Controller rotation video

## 2. Image Files (`assets/images/`)
- `cushion_exploded.png` — Exploded view of cushion internal layers
- `controller_unit.png` — Real physical controller unit photo

## 3. Font Files (`assets/fonts/`)
- `CalSans-SemiBold.woff2` — Cal Sans font file
- `CalSansUI-Regular.woff2` — Cal Sans UI font file

> Note: You can customize these file paths inside `app.js` under the `BASSCRAFT_CONFIG` object.
